# cria
> Geração de ideias híbrida humano-IA como mechanism design: diversidade coletiva vira payoff, grounding vira kill-test, ideia sobrevivente vira projeto com dono.

## What it does

- Roda ciclos de ideação (diverge → atrito humano → converge → kill-test → posse) sobre dossiês de crises documentadas
- Agentes LLM heterogêneos aplicam motores de criatividade (combinar, inverter, reescalar, transplantar, colher-waze)
- Score de fronteira semântica (embeddings) recompensa território novo — homogenização perde por construção
- Instrumenta tudo: cada ideia, voto, kill-test e pivot vira dado do experimento (paper twin)

Spec completa: [SPECS.md](SPECS.md).
